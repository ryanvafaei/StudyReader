## B23 mutation check (cannot be run in the cloud)

`testReturnInTheSearchFieldDoesNotOpenTheSelectedDocument` **passed**. The mutation (remove `|| session.isSearchFocused` at `LibraryView.swift:177` and expect a failure) needs an edit, so I did not run it. Why the test could pass without proving the guard (vacuous), for the main session to weigh:

1. **The flag is set by the command, not by real focus.** ⌘F calls `AppCommands.swift:151-154`, which sets `session.isSearchFocused = true` and lets `RootView.swift:54-56` push that into the field's focus. The test never asserts the field has keyboard focus (B23 item 1). If AppKit focus did not move, Return would go to the table, the hidden button is disabled by the flag, and the test passes anyway, while a real regression in the field focus path would not show.
2. **An NSSearchField may swallow Return and Escape before the hidden buttons see them.** `RootView.swift:57` attaches `.onSubmit(of: .search)`, so Return in the focused field is handled by the field's own action, and the field editor handles Escape. If AppKit offers the key to the field before the window-wide default-button key equivalent, the hidden button would not fire even with the guard removed, and the test passes with the mutation. Only the one-off mutation run settles this, as B23 says. If the mutated test still passes, the test is vacuous and should drive a case where the guard matters (for example type a query character first and check the library selection afterwards).
3. **The empty-query case can hide a second regression.** With a non-empty query the library is swapped out for the results (`RootView.swift:27`), so the guard only matters in the narrow empty-field state this test uses. That is intentional (the test header says so), but a mutation that breaks only the Escape path is caught only by the final menu check (`Edit Metadata…` still enabled), which does pass.
4. Smaller points: `tabTitles` is empty whenever the tab bar doesn't exist, so it also reads as "nothing opened" if the new reader window is slow to appear (the check comes 1 s after the key); B23 item 3 (assert `tabTitles.isEmpty` before `card.exists`) is not done.

Recommendation: do the mutation run at the next Mac session (or as a temporary CI-only commit made by the main session, never by ui-tester); if it passes with the guard removed, replace the test with one that proves real focus, for example the field's focus state if XCUITest exposes it on macOS (check first), or type a character and assert the library didn't open.
